# 생각의 문

중학교 1·2학년을 위한 개인 두뇌게임과 4인 모둠 방탈출입니다. GitHub Pages에서는 기존 개인전을 플레이할 수 있습니다.

## 모둠전까지 진행하기

[수업용 파일 받기](https://github.com/vvskns52-lang/logic-rooms-game/archive/refs/heads/main.zip)

1. 교사 Windows PC에 Node.js 22 이상을 준비하고 ZIP을 전부 풉니다.
2. 압축을 푼 폴더에서 `Start-Classroom.cmd`를 실행합니다. 교사는 실행 창에 나온 교사 주소를 열고 기존 개인전 진행 키를 입력합니다.
3. 학생들은 **처음부터 실행 창에 표시된 학생 주소**로 접속합니다. 학생과 교사 PC가 같은 네트워크에 있고 학생이 교사 PC의 8789 포트로 접속할 수 있어야 합니다. 개인전은 기존 온라인 서버를 사용하므로 교사 PC에 인터넷 연결이 필요합니다.
4. 개인전이 끝나면 교사가 결과 화면에서 **모둠 탈출전 열기**를 누릅니다. 학생들은 기존 별명으로 자동 이동하며 개인전 입장 순서대로 네 명씩 배정됩니다.
5. 예선을 먼저 탈출한 두 모둠이 같은 퍼즐로 동시에 결승을 시작합니다. 네 방의 송신기를 동시에 가동한 기록으로 우승을 가립니다.

수업 중에는 교사 실행 창을 열어 둡니다. 자세한 조작법은 [수업 안내](./수업-시작하기.txt)에 있습니다.
