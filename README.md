# 생각의 문

교사 화면에서 **개인전**과 **모둠전** 중 하나를 골라 방을 엽니다. 학생은 입장 코드와 별명을 입력합니다.

## 개인전
GitHub Pages 또는 교실 서버의 선생님 화면에서 개인전을 선택하고 기존 진행 키로 방을 만드세요. 학생은 다섯 자리 코드로 입장합니다.

## 모둠전 준비
[교실 실행 파일 다운로드](https://github.com/vvskns52-lang/logic-rooms-game/archive/refs/heads/main.zip)

교사 Windows PC에 Node.js 22 이상을 준비하고 ZIP을 전부 풉니다. Start-Classroom.cmd를 실행하고 교사 주소에서 모둠전을 선택하세요. 실행 창의 모둠전 교사 키로 방을 만들면 T로 시작하는 여섯 자리 학생 코드가 나옵니다. GitHub Pages의 모둠전 버튼도 교사 PC의 교실 서버를 엽니다.

학생은 같은 네트워크에서 실행 창의 학생 주소로 접속하세요. 네 명씩 한 모둠으로 예선을 진행하고, 먼저 탈출한 두 모둠이 결승에서 겨룹니다. 교사 PC의 8789 포트에 접속할 수 있어야 합니다. 자세한 내용은 [수업 안내](./수업-시작하기.txt)를 참고하세요.
